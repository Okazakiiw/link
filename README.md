# VideoVault

เว็บฝากวิดีโอแบบใส่รหัสผ่านก่อนดู (ทำงานฝั่ง browser ล้วน ไม่มี backend)

## รันทดสอบในเครื่องตัวเอง

```
npm install
npm run dev
```

## Deploy ขึ้น GitHub Pages

1. สร้าง repo ใหม่บน GitHub (public)
2. push โค้ดทั้งหมดขึ้น branch `main`
3. เข้า repo → Settings → Pages → Build and deployment → Source เลือก **GitHub Actions**
4. push อีกครั้ง (หรือรอ workflow รันจากการ push ครั้งแรก) — ดูสถานะที่แท็บ Actions
5. เสร็จแล้วเว็บจะอยู่ที่ `https://<username>.github.io/<repo-name>/`

## ข้อควรรู้

- ข้อมูลวิดีโอ/รหัสผ่านเก็บใน `localStorage` ของเบราว์เซอร์ผู้ดูแลเท่านั้น — ถ้าเปลี่ยนเครื่อง/เบราว์เซอร์ ข้อมูลจะไม่ตามไปด้วย และถ้าคนอื่นเปิดเว็บนี้ เขาจะไม่เห็นรายการวิดีโอที่คุณเพิ่มไว้ เพราะเก็บแยกเครื่องใครเครื่องมัน
- เหมาะสำหรับทดสอบ/ใช้ส่วนตัว ไม่เหมาะกับให้หลายคนช่วยกันจัดการวิดีโอพร้อมกัน (ต้องมี backend จริงตามสเปกที่แยกให้ไว้ก่อนหน้า)
- รหัส Admin เริ่มต้น: `admin1234` — แก้ได้ในไฟล์ `src/VideoVault.jsx` ตรงบรรทัด `ADMIN_CODE`
